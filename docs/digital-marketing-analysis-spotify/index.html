Introduction

Spotify is a leading global audio streaming platform, founded in 2006 in Sweden, that provides on demand access to millions of songs, podcasts, and other audio content.

The Dataset

This analysis uses the Spotify Music Analytics Dataset from Kaggle, covering songs released between 2015 and 2025.

Strengths and Weaknesses

What works, and what does not.

Strengths

Weaknesses

Test 1: Release Day

Average streams by day of release.

Ho: The day of the week a song is released has no effect on its average stream count.

Ha: The day of the week a song is released does affect its average stream count.

Goal: Identify whether certain release days lead to higher engagement so marketing campaigns can be optimized around high performing release days.

Highest: Friday at 237,451 streams, followed by Sunday and Saturday.

Lowest: Wednesday at 144,851, followed by Thursday at 156,490.

Takeaway: Release day matters. Weekend releases perform better.

Analytical Tools

Tools used to collect, analyze, and visualize the data.

Data Collection

Kaggle and CSV. The dataset was already precompiled on Kaggle, making it easier to access.

Data Analysis

R, using dplyr and tidyverse for filtering, grouping, and summarization, plus lubridate for simplifying dates and built in statistical functions in R.

Data Visualization

ggplot2 in R, used to build the bar charts.

08

Conclusion

The ecosystem assessment revealed Spotify's strong personalization and cross platform design, along with opportunities to improve social features and influencer integration. The A/B testing demonstrated that release timing and genre significantly influence streaming performance, with Hip Hop as the top genre in the United States, providing clear marketing insight. The analytical tools, Kaggle and CSV, R, and ggplot2, supported a full analysis of Spotify's trends and user behavior.
